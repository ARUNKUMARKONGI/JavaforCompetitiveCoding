# Java for Competitive Coding
## Data Types knowledge

In Java, data types specify the size and type of values that can be stored in an variable. They are broadly categorized into **Primitive Data Types** (e.g., `int`, `double`, `boolean`) and **Non-Primitive Data Types** (e.g., `String`, `Arrays`).
